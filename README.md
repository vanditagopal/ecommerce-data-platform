# E-Commerce Data Platform

An end-to-end e-commerce data platform focused on data engineering,
data pipelines, data quality, and automation.

## Goals

- Build batch and streaming data pipelines
- Learn Apache Spark and Databricks
- Implement Bronze, Silver, and Gold data layers
- Build data quality and validation frameworks
- Build an automated E2E testing framework
- Explore AWS cloud services
- Build a lightweight frontend and backend
